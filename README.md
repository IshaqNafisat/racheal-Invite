# RJ27 Wedding Invitation
1. Edit the `CONFIG` block at the top of `src/App.jsx` (WhatsApp numbers, gift accounts).
2. Add `public/assets/couple.jpg` (couple photo) and `public/assets/music.mp3`.
3. `npm install && npm run dev` to preview, `npm run build` to test.
4. Push to GitHub, import into Vercel (Framework: Vite). Done.
